# SG-MRM Sample Data

This folder provides representative samples from the **SG-MRM (Satellite-to-Ground Multi-scale Radio Map)** dataset.

## Contents

The current release contains:

- **Scenario:** Huashan Mountain
- **Data type:** Electromagnetic map visualization (PNG)
- **Number of frames:** 12 consecutive frames
- **Temporal resolution:** 10 s/frame

These samples illustrate the temporal evolution of the satellite-to-ground electromagnetic propagation field as the serving satellite moves along its orbit.

## Full Dataset

The complete SG-MRM dataset includes:

- 4 representative scenarios
  - Xi'an Urban
  - Qinling Mountains
  - Huashan Mountain
  - Loess Plateau
- Continuous observations from **2025-05-01** to **2025-05-07**
- Temporal resolution of **10 seconds**
- **241,920** electromagnetic map samples
- Approximately **60 GB** of raw propagation data with corresponding metadata

## Notes

This repository currently releases representative visualization samples together with the data generation code.

The complete dataset is available for academic research upon reasonable request.
